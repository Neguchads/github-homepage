# Decisions

## 2026-11-25 — NAVI identity and NEF adoption

Choose a distinct maintained identity and centralized credits rather than rewriting history. Retain MIT notices, compatible routes, themes and existing directory boundaries. Remove inactive or upstream-coupled automation rather than blindly transferring write permissions. Preserve reviewed Core pilot pin. English and Portuguese are the maintained documentation languages; runtime locales remain unchanged. The package is private to prevent accidental npm publication; package identity changes are recorded in the lockfile. Public hosting and graph publication remain separate approval steps.
