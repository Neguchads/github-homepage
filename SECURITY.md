# Security policy

The maintained branch is `main`; no response SLA is promised.

Use the repository's [private vulnerability reporting](https://github.com/Neguchads/navi-githomepage/security/advisories/new) if enabled. If unavailable, contact the maintainer through a verified private channel before sharing sensitive details. Never post tokens, private repository data, or exploit details in public issues.

Public SVG endpoints must use credentials restricted to public data; review all token-accessible data, outbound requests and status endpoints before deployment. Do not enable private stats on a public service. Use reviewed public-only graph snapshots and static assets. Report dependency vulnerabilities to their respective maintainers as appropriate.

Publication and deployment require explicit approval and evidence; see [Architecture](docs/ARCHITECTURE.md) and [NAVI pilot](docs/NAVI_PILOT.md).
